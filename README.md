# 🦑 Sistem Pengurusan Trip & Tabung

Aplikasi web mudah alih (*mobile-first*) untuk pengurusan kutipan tabung, rekod perbelanjaan, tentatif, dan senarai semak (*checklist*) secara masa nyata (*real-time*).

---

### ✨ Ciri-Ciri Utama
* **Tabung & Bajet:** Semakan status bayaran individu, jumlah terkumpul, dan anggaran perbelanjaan.
* **Rekod Perbelanjaan:** Laporan terperinci transaksi beserta paparan resit digital.
* **Tentatif & Checklist:** Paparan jadual aktiviti dan senarai kelengkapan secara interaktif.
* **Panel Pentadbir (Admin):** Kemas kini data terus daripada pelayar dengan kawalan akses terhad.

---

### 🛠️ Teknologi Digunakan
* **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla JS), FontAwesome
* **Backend & Database:** Supabase (PostgreSQL, Authentication & Storage)
* **Hosting:** GitHub Pages
